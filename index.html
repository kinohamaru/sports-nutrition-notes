対象必要量
アスリート1.5〜2.0 g/kg/日
一般人1.0 g/kg/日
70kgアスリートの場合140 g/日
  • 運動後 1時間以内に20g 摂取（推奨：牛乳）
  • 1食の最大吸収量：40 g
  • 効果は摂取後 24時間 持続

超回復の仕組み

運動 → 筋繊維に微細損傷
↓
休養＋栄養（タンパク質）
↓
より強く回復（超回復）
  • 過負荷の原則：漸進的に強度を上げないと超回復しない
  • サテライト細胞：損傷した筋繊維を修復・新繊維を生成する幹細胞
  • 筋肥大開始：3ヶ月〜　筋繊維数増加：6ヶ月〜

加齢と筋肉の問題

  • ロコモ：加齢→運動器（筋・骨・関節）機能低下→日常生活困難
  • サルコペニア：骨格筋量・筋力の低下（加齢性筋萎縮）
  • フレイル：虚弱状態（サルコペニア＋骨弱体化）

BCAA（分岐鎖アミノ酸）

  • 種類：ロイシン・イソロイシン・バリン
  • ホエイ（乳清）＞大豆タンパク（BCAA多い）
  • BCAA 3g ≒ ホエイタンパク 20g
  • 中枢性疲労を抑制（トリプトファンと競合し脳への流入防ぐ）

カルシウム（骨）

  • 骨代謝：骨吸収（破骨細胞）⇔ 骨形成（骨芽細胞）
  • 運動 → 衝撃 → 電気的刺激 → Ca沈着・骨芽細胞活性化
対象必要量/日
アスリート1500 mg
一般男性800 mg
一般女性650 mg
  • Ca吸収率：30〜50%（18〜29歳：35%）
  • 促進：タンパク質（×3倍！）・ビタミンD・ビタミンC
  • 阻害：タンニン・過剰リン・食物繊維・過剰タンパク
  • Ca vs 鉄は吸収競合 → 2時間ずらす
LEA（利用可能エネルギー不足）→ 身長の伸びが停止！

📸 3 / 8　水分補給・疲労
❸ 水分補給・疲労
スポーツ栄養学 テスト対策ノート

水分補給

脱水量影響
体重の2%パフォーマンス低下
体重の5%熱中症・痙攣
体重の10%以上生命の危険

補給のポイント

  • 運動前：500mL（2時間前）
  • 運動中：15〜20分ごとに150〜250mL
  • 運動後：失った体重の150% を補給
  • 60分以内 → 水でOK
  • 60分超 → スポーツドリンク（糖質6〜8%＋電解質）
発汗で 水分＋電解質（Na・Cl・K） が失われる
→ 水だけ飲む → 血液が薄まる → 低ナトリウム血症（偽性脱水）
→ 電解質の補給が必須！

疲労の種類

末梢性疲労（筋肉）

  • 乳酸・H⁺蓄積：pH低下 → 筋収縮障害
  • グリコーゲン枯渇：燃料切れ
  • 筋損傷：微細断裂 → DOMS（遅発性筋肉痛）

中枢性疲労（脳・神経）

長時間運動 → 血中遊離脂肪酸↑
→ トリプトファン(Trp) が脳に多く流入
→ セロトニン↑ → 眠気・疲労感（セロトニン仮説）
→ BCAAがTrpと競合 → 中枢性疲労を抑制！

疲労回復に必要な栄養

  • 糖質：グリコーゲン再合成（運動直後が最速）
  • タンパク質・BCAA：筋修復
  • ビタミンC：活性酸素除去
  • 睡眠：成長ホルモン分泌 → 筋修復最大化

グリコーゲンローディング

時期内容
1週間前枯渇運動（使い果たす）
6〜4日前低糖質食 ＋ 軽運動
3〜1日前高糖質食 ＋ 休息 → 超回復
  • → 筋グリコーゲン 通常の1.5〜2倍 蓄積 → 持久力UP
  • 体内貯蔵：肝グリ100g ＋ 筋グリ300〜400g
  • 持久系の糖質必要量：7〜10 g/kg/日

体脂肪と減量の計算

  • 体脂肪の組成：水分20% ＋ 脂肪80%
体脂肪1kg ＝ 1×0.8×9kcal ＝ 7200 kcal
→ 1kgの減量には7200kcalの消費が必要

オフシーズン太りのしくみ

練習日 − 休息日のエネルギー消費差 ≒ 1000kcal/日
↓
1000kcal × 7日 ＝ 7000kcal/週 の余剰
↓
7000kcal ≒ 体脂肪 約1kg/週 蓄積！
（引退後も同様のリスクあり）

正しい減量法（ナガサキ式）

ポイント：ちょっとの食事制限 ＋ ちょっとの定期的な運動
→ 運動だけでは限界がある
→ 食事との併用 が最も効果的！
